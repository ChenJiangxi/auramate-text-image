# 节令热点 · 日历就是选题表

节令是这个品牌**最不用解释就成立**的选题 —— 玄学和节气本来就是一套时间系统，讲节气不需要绕壳子。

## 时间规则（最重要）

**提前 3–7 天发。** 当天发已经晚了 —— 用户在节点前找内容，节点当天在过节。

| 节点 | 提前 | 说什么 |
|---|---|---|
| **立春** | 7 天 | 一年的起点（比元旦更是"新年"）· 全年基调 |
| **春节 / 新年** | 7 天 | 全年运势 / 新年壁纸（`cny-wallpaper` `cny-greeting`） |
| **开工日** | 3 天 | 节后综合症 / 今年的工作节奏 |
| **清明** | 3 天 | 家族 / 父母缘（`professional-report` 里的家庭结构） |
| **入夏 / 三伏** | 5 天 | 养生 · 五运六气（`health-wuyun`）★ 已做过 |
| **秋分 / 换季** | 3 天 | 状态调整 |
| **冬至** | 5 天 | 一年最重要的节点之一 · 复盘 |
| **生日月** | 随时 | 本命年 / 生日那天的时间坐标 |
| **考试季 / 求职季** | 7 天 | `offer-advisor` `offer-wish` |
| **年末** | 10 天 | 年度复盘 + 明年展望（`fortune-2026` `life-kline-pro`） |
| **产品周年** | 7 天 | 品牌叙事 |

**24 节气**本身就是一份现成的全年内容日历。做一个 `SCHEDULE.md` 排进去，别临时想。

## 为什么节令帖安全

节气是**公认的传统文化**，不是玄学。讲「冬至是一年里白天最短的一天，古人认为这天开始阳气回升」完全不触发任何审核。

这让节令帖成为**账号被限流后最好的洗白内容**：
- 零红线
- 有流量
- 顺带带出产品功能

## 两条路线

### A · 节气文化 + 功能桥（主力）

```
封面：这个节气是什么 / 一个反常识点
2：古人怎么看这一天（文化壳，讲人话）
3：它对应到现代生活是什么（桥）
4：产品截图（相关功能）
5：落点
```

例（三伏 → `health-wuyun`）：三伏是一年里身体最需要"降载"的一段 → 五运六气是一套一千年前的季节-体质对应表 → 我们把它做成了一份体检式报告 → 五脏雷达图截图 → 落点。

### B · 实用清单型（收藏率高）

```
封面：{节气}这几天，适合做的三件事
2-4：每张一件事 + 一句依据
5：产品里怎么看你自己的
```

清单型收藏率远高于赞。**注意不要写成"宜忌"** —— 那是黄历，直接踩线。写成"适合 / 不太适合"的生活建议。

## 热点借势

蹭影视 / 明星 / 社会话题的「人格分析」角度。

**风险很高，规则严格**：

```
❌ 不分析真实公众人物的命理（涉及他人 + 玄学双重风险）
❌ 不碰社会负面事件（灾难 / 事故 / 犯罪）
❌ 不碰政治 / 医疗 / 财经的具体预测
✅ 可以蹭：影视剧角色（虚构人物）、流行心理概念、集体情绪（"周一综合症"）
✅ 可以蹭：其他 AI 产品的话题（"AI 抢饭碗"→ 我们的专业报告）★ 已做过
```

已跑通的热点例：`post-ai-suanming`（算命被 AI 抢饭碗 → 专业报告）。

## 视觉

模板 A 渐变编辑风。节气帖可以在配图上做文章：

- codex-image 生成节气氛围插画（暖色、无字、编辑风）
- 产品里的节气相关截图（`health-wuyun` 的五运六气板块、`cny-wallpaper`）
- **不用素材图库的俗气节气图**（红灯笼、饺子、二十四节气标准配图）

## 红线

```
□ 不写「宜 / 忌」（黄历格式直接踩线）
□ 不预测节气期间的疾病 / 灾祸
□ 「养生」可以说，「治病」「调理」慎用（医疗承诺）
□ 节气 + 「转运」= 双重违禁
□ 不分析真实公众人物
□ 新年帖不写「新年转运」，写「新一年的节奏」
```

## 排期建议

在 repo 里维护一份 `SCHEDULE.md`：

```markdown
| 日期 | 节点 | 提前几天 | 角度 | 功能 | 状态 |
|---|---|---|---|---|---|
| 2026-02-04 | 立春 | 7 | 一年真正的起点 | life-kline | 待做 |
| 2026-02-17 | 春节 | 7 | 新年壁纸 | cny-wallpaper | 待做 |
```

每月初把下个月的节点排进去，比临时找选题效率高一个量级。

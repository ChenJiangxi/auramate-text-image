# 日签日更 · 底噪

**这类不追求爆，追求在。** 作用是保持账号活跃度、喂算法、让老用户每天有个理由回来。

已跑通：post-005「灵签每日一句」（6 张，cover + 4 张真实灵签截图 + 收尾）。

## 产品侧的原料

灵伴每天给用户一条**灵签**：一句话，不是一篇解读。生成逻辑 = 时间坐标 ⊕ 你的出生数据 ⊕ 它对你 N 天的记忆。

关键卖点（也是文案角度）：**它是主动的，不是你去问的。**

> 很多人状态不行才想到算一算。但你需要的可能不是一堆解读、不是一篇鸡汤，是一句真话。

这个「主动 vs 被动」的反差是这条线的核心叙事，别丢。

## 两种做法

### A · 单图日更（最省，日常用）

一天一张。1080×1920 或 1242×1660。

```
内容 = 灵签那句话（大字）+ 当天形态名 + 灵体视觉 + 品牌签
```

- 用**真实灵签截图**最好（产品里那一屏本身就美）—— 用户原图直接用，不要再加工
- 需要自己排版时用模板 A，字号统一，一句话居中偏上，灵体在下

### B · 周合集（每周一次，效果更好）

一周七条攒成一篇 4–6 张：

| # | 内容 |
|---|---|
| 1 | 封面：这周它跟我说的七句话 |
| 2–5 | 每张 1–2 条真实灵签截图 |
| 6 | 落点：哪一句今天真的应验了 / 哪一句我当时不信 |

周合集比单图日更**互动高得多**，因为有叙事。日更保曝光，周合集保互动，两个都做。

## 批量生产

日更的关键是**别每天现做**。一次做一周：

```bash
# 1. 攒素材：让用户一次发一周的灵签截图，或从产品批量截
# 2. 统一裁切
for f in raw/*.png; do /usr/bin/python3 -c "..."; done
# 3. 批量套模板 → render.js 一次渲染全部
# 4. 存 posts/daily-{YYYY-MM-W}/，按日期命名
```

用户之前一次性提供过多张真截图（`slide-02-img_8009.png` 这种命名 = 手机原图直出）。**用原图不要再加工** —— 2026-05-10 用户原话：「用原图不需要再加工了」。

## 红线

日签是最容易松懈的地方，但**灵签文案本身可能带风险词**：

```
□ 灵签句子里有没有「贵人」「转运」「化解」—— 「贵人」是灰区（口语化可用），
  「转运/化解」直接换
□ 有没有预测危险事件（疾病 / 灾祸）
□ 「灵签」是产品名，可以用；但别配「算一算」「准不准」
□ 图里不要出现完整的运势解读段落（那是"信息"）
□ 每天发不要用完全相同的文案，会被判重复内容
```

安全的日签句式：状态描述 + 行动建议，不做承诺。
- ✅「今天脑子先到一步，别急着开口」
- ✅「因为日落是时间的具象化」
- ❌「今天贵人相助，财运亨通」

## 标题 / 正文

日更帖的正文可以很短（100–200 字）。

```
灵伴今天跟我说：{那句话}

{一两句我的反应 / 这句话对上了什么}

（它每天早上写一句，不是我去问的）
```

标题直接用那句灵签，或者「它今天说了句让我愣住的话」。

## 频率

- 单图日更：每日或隔日
- 周合集：每周一次
- **日更不计入内容配比**，它是底噪，不占主线名额

如果日更质量下滑（凑数、重复），**宁可停掉**。低质日更比不发更伤账号。

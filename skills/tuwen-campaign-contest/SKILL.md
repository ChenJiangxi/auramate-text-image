# 活动 · 办比赛，不办抽奖

## 为什么是比赛不是抽奖

**抽奖**：用户留个言 → 你抽 → 结束。零内容沉淀，且抽奖是平台重点监控的营销行为，
高危账号期风险大于收益。

**比赛（灵体大赏）**：用户带话题标签发自己的笔记 → 产出 UGC → 你评选 → 发公示合集。

| | 抽奖 | 比赛 |
|---|---|---|
| 内容沉淀 | 无 | 一批带话题的用户笔记 |
| 展示产品 | 靠你自己说 | 靠一堆用户晒出来的真灵体 |
| 合规风险 | 高（诱导互动） | 低（正常发笔记，平台鼓励内容共创） |
| 传播 | 只在你这条底下 | 每个参与者的粉丝都看到 |

**灵体是这个产品最好看的东西**，让用户自己晒出来，比任何功能介绍都有说服力。

## 奖品：月度会员

- 虚拟、边际成本低、直接拉留存 —— 拿到的人下个月还会回来
- 不要实体周边（要地址 = 收集个人信息，高危期别碰）
- 数量 10 个左右。少了没人参与，多了显得不值钱

### ⚠️ 发放链路先确认

产品出过**系统级 bug：Stripe webhook 从未触发积分 grant，100+ 付费用户没拿到**。

办活动前跟工程侧确认会员发放链路是通的，并备好手动补发路径。
**中奖了拿不到东西，比不办活动伤害大得多。**

## 合规：怎么让人参与

**绝对不能写**：
```
❌ 评论区扣 1 / 评论区发你的灵体
❌ 关注 + 点赞 + 收藏三连才有资格
❌ 私信我领取 / 加 V
❌ 转发到朋友圈截图给我
```

**正确做法**：
```
✅ 带话题标签发一条自己的笔记（平台鼓励内容共创，不算诱导）
✅ 正文只陈述规则，不下指令：「带上标签发出来就行」
✅ 明确说「不用在评论区做什么，也不用私信我」—— 既合规又降低参与门槛
✅ 评选完发一条公示合集，把入选的放一起
```

话题标签建议 `#灵体大赏`，短、好记、可长期复用成系列。

## 分镜（3 张）

活动帖要短。长了像广告。

| # | 页型 | 内容 |
|---|---|---|
| 1 | 封面 | 「灵体大赏：谁的那颗最好看」+ 多个真实灵体拼的横带 |
| 2 | 正文 | 为什么办 + 怎么参加 + 奖品。三段说完 |
| 3 | 正文/图 | （可选）往期入选合集，或规则补充 |

**2 张版**更安全。模板 → `templates/editorial-gradient/`

配图用**多个不同的真实灵体拼成横带** —— 直接呼应「大赏」，也展示了多样性。
⚠️ 别跟其他帖复用同一条横带（见 `auramate-tuwen/references/04-assets.md` 配图三问）。

## 文案模板

```
每个人的灵体都是按自己那份出生时间数据算出来的一颗，颜色、形状、亮的位置全不一样。
看得多了会发现，有些人的那颗是真的好看。

所以办一次灵体大赏：带话题标签发一条自己的笔记，把你那颗放出来就行。
我们挑十个，各送一个月会员。

不用在评论区做什么，也不用私信我，正常发笔记。
挑完发一条公示，把入选的十颗放一起——那张图应该会很好看。
```

要点：不喊「福利」「限时」「速抢」；保持第一人称手记口吻；收尾落在「那张图会很好看」而不是催参与。

## 频率

一个月最多 1 次。做成季度性的系列（`#灵体大赏` 第一期 / 第二期）比高频办更有积累。

## 交付时附的说明

写进 `content.md`：

```markdown
## 活动合规说明
- 形式：话题标签征集（非抽奖组件，非评论区互动）
- 标签：#灵体大赏
- 奖品：10 × 月度会员。发放链路已确认可用：是 / 否
- 评选标准：{说清楚，避免争议}
- 公示：评选后发合集笔记
- 账号风险评估：账号当前 {状态}，本月已发活动帖 {N} 篇
```

# 叙事随笔 · 主力线

**这是最稳的一条线。** 判不准选题类型就走这条。

风险最低（天然 AI 科技向 + 图里只有短句）、复用最强（骨架固定）、已跑通 6 篇以上。

## 万能骨架

```
痛点 → 缺的那个东西 → 功能正好给了它 → 哲思落点
```

四步都要落在**具体**上，任何一步抽象了整篇就垮。

真实样例（post-digu-kline）：

| 步 | 内容 |
|---|---|
| 痛点 | 高敏 + 带旧伤 + 野心家，一到低谷只会往自己身上问「是不是我不够好」 |
| 缺的 | 一把**尺子** —— 量不出这段难有几分是自己、几分是时运 |
| 功能 | 人生 K 线（`life-kline`）：把一生运势画成有涨有跌的线 |
| 落点 | 命理不是免罪符（甩锅给命），是一个**坐标**（知道自己正站在低处，会过去） |

## 分镜（6 张标准版）

| # | 页型 | 内容 |
|---|---|---|
| 1 | 封面 | kicker「灵伴 AI · {系列名}」+ 大标题 68px（3 行，accent 词标紫）+ codex 插画 + footer |
| 2 | 正文 | 痛点。3 段写满，具体到细节 |
| 3 | 正文 | reframe + 带出功能。3 段 |
| 4 | 产品图 | head 52px「{一句说明}」+ 产品截图（主视图，信息密集那张）+ foot 标注 |
| 5 | 产品图 | head + 产品截图（细节视图，点开某一项）+ foot 标注 |
| 6 | 正文 | 哲思落点。3 段，最后一段 weight 500 |

**4 张压缩版**：封面 / 痛点+reframe / 产品图 / 落点。用户明确要短的时候用。

模板 → `templates/editorial-gradient/`

## 视觉规格（照抄，别改）

```
1242×1660

```

## 文案要求

**每张写满字。一张 2–3 段，别一段一张、别大片留白。** 整篇 500–700 字压成 4–6 张。

用户 2026-07-01 原话：「一张图写满字」「不是一个段落一张图」。

其余照 `auramate-tuwen/references/03-copywriting.md`：人味儿、讲具体、不写金句、无字间空格。

## 从「用户丢来一个钩子」到成稿

这是最高频的工作模式。用户会发一张别人的抖音封面截图 + 一句「下一个选题：按如图的方向呢」。

1. **读它的角度，不是它的视觉。** 那张封面多半是深色大字 meme 风 —— 我们不学视觉，只学角度。视觉永远用锁定的渐变模板。
2. **把钩子映射到一个真实功能。** 功能清单在 `auramate-tuwen/references/00-brand.md`，源在 `~/Code/metamate/src/plugins/config.ts`。
3. **写出那座桥。** 「这类人缺的是 X，这个功能正好给 X」。桥不成立就换功能，别硬接。
4. **renwei + 哲思写文案。** 常用创始人手记口吻：「我做的这个 AI…」「所以我做了个东西，叫…」。
5. **配图**：codex 插画（封面）+ 真实产品截图 ×2（内页）。
6. **交付**：全套 slide + 分镜说明 + 红线提醒，写进 `content.md`。

## 常见翻车

| 症状 | 原因 | 修法 |
|---|---|---|
| 用户说「太浅」 | 落点停在鸡汤 | 往哲思推一层：不是"会好的"，是"这件事的位置在哪" |
| 用户说「绕口」 | 用了字间空格 / 抽象比喻 | 写正常中文，换具体名词 |
| 用户说「封面不够醒目」 | 标题字号没到 82 / 没铺满 | 放大到 82，或减字改 2 行 |
| 图看着空 | 一段一张 | 合并成 2–3 段一张 |
| 桥很硬 | 功能选错 | 换功能，或换钩子 |

# 00 · 品牌 / 产品 / 受众

## AuraMate 灵伴是什么

玄学 AI 助手。`auramate.net`。工程 `~/Code/metamate`（Next.js + Chroma 向量库 + 五运六气知识库 + OpenRouter 多模型路由）。

**一句话**：把你的出生时间数据，翻译成一个能陪你过日子的 AI。

### 旗舰功能：灵体（Spirit Companion）

用户的四柱 → 十神 / 强弱 / 格局 / 用神 → LLM 出 JSON（theme / insight / personalityBase / visualSubject / visualColor）→ SeedDream 出图，生成一个 512×512 的抽象粒子光球，这就是你的「本命灵体」。

- 灵体有性格基线，每天给你一条**灵签**（一句话，不是一篇解读）。
- 用户每晚反馈「这句准不准」→ 灵体调整自我认知。这是产品最打动人的点：**它会因为你而变**。
- 灵体每天还会呈现一种**形态**（十种，对应十神），见 `tuwen-knowledge-decode`。

**内容侧红线**：代码里有「灵魂架构师」「灵魂能量」这种词 —— 对外文案**绝不用**。换成「个性本质」「你的盘 / 盘面」。

## 受众画像

- 25–35 岁女性为主
- 对自我探索 / 命理 / 心理学好奇，但**不是**技术背景
- 会被「有人认真理解我」打动，不会被「限时优惠」打动
- 讨厌被说教，讨厌鸡汤，讨厌明显的营销

**写给她的时候**：像一个懂技术但不炫技的朋友，在讲自己做的一个东西，顺便讲了点真话。

## 调性

| 要 | 不要 |
|---|---|
| 软温感、茶室美学、留白克制 | 赛博朋克、荧光、夸张动效 |
| 第一人称、具体、承认不确定 | 全知视角、抽象口号、绝对断言 |
| 「我做了个东西」 | 「重磅上线 / 全球首个 / 颠覆」 |
| 情绪真实 | 情绪表演 |

# 03 · 文案

**先把文案写完，再想图。** 图是文案的容器，反过来做一定翻车。

## 一、总原则：人味儿

这套调性来自 `renwei-writing` skill（橘子 orange2ai 开源，`~/.claude/skills/renwei-writing`）。核心三件事：

- **位置** —— 一个具体的人，站在具体位置说话。不是全知视角。
- **代价** —— 判断是拿身体 / 情绪付过代价换来的，不是想出来的。
- **手迹** —— 冗余、语气词、忽长忽短，是那个人说话的样子。

### 打磨用户自己写的文字时

**只做减法、少动。** 一段动三处是常态，动十处是事故。毛边先假设是手迹不是瑕疵。拿不准就白描。改完逐处交代，不确定的标「可还原」。

**用户亲自改过的句子视为定稿锚点。** 除非用户明确要求重写，只能改标点、空格、断行和明显错字；
核心名词、人物关系、语气顺序都保留。不要因为自己有一套标题公式，就把用户已经找到的准确表达重新“优化”成模板句。

### AI 腔警报清单（写完自查）

命中任何一条就重写那句：

```
意义拔高    「标志着」「体现了」「折射出」「不仅仅是」
宣传腔      「赋能」「打造」「匠心」「深耕」「全新升级」
不是X而是Y  这个句式本身就是警报
排比三连    「更X、更Y、更Z」
同义词轮换  同一个东西在一段里换三种说法
假范围      「从X到Y」
格言公式    「X是Y的语言」
短句轰炸    连续五个四字短句
自问自答    「为什么？因为」
假坦诚开场  「说实话」「不瞒你说」
```

## 二、讲具体，不讲抽象

用户 2026-07-01 反复拒稿的核心都是「花 / 乱 / 绕」。

| ❌ 抽象 | ✅ 具体 |
|---|---|
| 那个专业不是我 | 我学的会计，后悔了五年，一对上报表数字就提不起劲 |
| 低谷期很难熬 | 事情搞砸了，关系散了，钱也紧了 |
| 它很懂我 | 发疯日那天我真的发了一条很长的 status |

**不要用字间空格做节奏**（「它说 —— 我当年 那个 专业」），写正常中文。

## 三、别把「不营销」写成「含糊」

**反营销腔的解药是「具体」，不是「装谦虚」。** 这是最容易过度矫正的地方。

| ❌ 营销腔（夸大 + 情绪动员） | ❌ 含糊（什么都没说） | ✅ 具体（平实说清楚） |
|---|---|---|
| 重磅上线！全新旺运地图 | 做了点东西 | 新功能 · 旺运地图 |
| 超值福利限时抢 | 送几份 | 抽奖 · 30 份深度报告 |
| 灵伴碾压全部大模型 | 我们做了个测试 | 模型测评 · 四届专家赛真题 |

**顶栏 kicker 是给读者定位用的，不是发挥文案的地方。**

- **大标题**负责钩情绪 —— 写痛点，不写功能名
- **kicker / footer** 负责说清楚这是什么栏目、什么功能 —— 写具体，不写俏皮话

两个搞反了（标题写成功能名很干、kicker 写成俏皮话没信息）是这类帖最常见的失手。

> **真实翻车（2026-08-10）**：功能更新的 demo，kicker 写成「灵伴 AI · 做了点东西」。
> 用户一句「你直接把功能更新放到标题里不就好了」。确实 —— 那个位置本来就是用来说清楚的，
> 装谦虚不会显得不营销，只会显得没内容。同批还有「送几份」「我们做了个测试」两处同样毛病。

## 四、标题

小红书标题是唯一的流量入口。四种已验证的写法：

### 1. 反预期 + 第一人称
> 我让 AI 回看 18 岁的我，它说我当年那个专业其实选错了

### 2. 痛点直击 + 身份标签
> 低谷期最大的坑，是你把自己活成了替罪羊

### 3. 工程师视角自嘲
> 把一个中国算命 App 卖给老外，我做了什么

### 4. 提问钩 + 反常识
> 你要等到状态不行才想算一算？我让 AI 每天主动给我一句

**规则**：
- ≤ 20 字最好，最多 25；但这是排版建议，不能拿它换掉用户原句里的情绪主体
- 必须有情绪或反预期，**不要抽象口号**
- 违禁词扫一遍（标题是最容易被机器抓的地方）
- 封面大字可以是标题的浓缩版，不必一字不差

### 情绪主体不能被优化掉

标题缩短时，先删栏目标签和功能操作词，最后才碰情绪句。判断一个词能不能删，不看它是不是品牌名，
看删掉以后「谁和谁发生了什么」还在不在。

```
发布标题：功能更新：那些被灵伴 AI 说中的话，我终于存下来了
封面 kicker：灵伴 AI · 功能更新 · 对话导出
封面大字：那些被灵伴 AI 说中的话，我终于存下来了
```

这里 `功能更新 / 对话导出` 是栏目和操作，可以移到 kicker；`灵伴 AI` 是「谁说中了我」，
属于情绪关系，不能为了凑字数改成「有些话」。封面还是太长，就用三行断句和较小一档标题字号解决。

> **真实返工（2026-08-10）**：用户连续两次反馈「我觉得标题很不吸引人」「标题真的很不吸引人」，
> 最后亲自定下「功能更新：那些被灵伴AI说中的话，我终于存下来了」。这次的问题不是缺一个爆款词，
> 是之前的改写把 `灵伴 AI` 和「被说中」这层具体关系写淡了。

## 五、正文页字数：**每张 280–340 字**，这是硬指标

「每张写满字、别大片留白」这句话我在这份 skill 里写过三次，然后**连续违反了二十次**。
2026-08-10 用户发来 demo 截图：底下三分之一全空。一量，20 张正文页**全部**没写满，
平均只填到 50–60%，多数在 120–230 字。

原因不是不懂规则，是「满不满」靠肉眼估，一忙就放过去了。所以改成数字：

```
正文页 44px / line-height 1.9 / 内容宽 1066px
  → 每行约 24 字，每行占 84px
  → 正文块可用高度约 1290px ≈ 15 行
  → 目标 280–340 字/张
  → 低于 260 字，底部一定空一块
```

**修法永远是「加字」，不是「改排版」。** 别去调字号行距把短文案撑开 —— 那是掩盖，
读者看到的还是一张信息量不足的图。加的必须是**真内容**：多一个具体例子、
多一层解释、多一句反面情况。灌水凑字数比留白更糟。

### 跑脚本，别靠眼睛

```bash
node tools/check-fill.js posts/post-xxx/     # 量每张正文块底部的空隙
```

输出 `✓ 填充 96% 293 字` 或 `✗ 填充 56% 底部空 589px 155 字`。
**出图后必跑**，跟 `redline-scan.sh` 一样是发布前的两道机械关。

## 六、正文结构

小红书正文 300–600 字最佳。标准五段：

```
1  钩子     一句话把人拽进来。常用「继续上个月那个…」建立连续感
2  场景     具体的痛 / 具体的事。用第一人称，带细节
3  转折     「后来我慢慢想明白」—— reframe，把痛点重新定义
4  功能     自然带出产品做了什么。别推销，就说「所以我做了个东西」
5  落点     哲思 / 自我关怀。不喊口号，落在一个具体的感受上
```

**收尾不要 CTA。** 「评论区扣 1」「私信我」都是 redline。可以用一句开放的话自然引出互动，比如「你今天是哪一种」，但不要指令性话术。

## 七、把钩子桥到功能（最关键的一步）

日常最高频的工作模式：用户丢来一个热点 / 一张别人的爆款封面 / 一个心理概念，说「下一个选题按这个方向」。

**做法**：

1. **读钩子的「角度」，不是它的视觉。** 视觉永远用我们锁定的模板。
2. **找一个真实存在的功能当落点**（清单在 `00-brand.md`）。
3. **写出这座桥。** 桥要成立在逻辑上，不能硬接。

桥的经典写法 —— 「这类人缺的是 X，而我们这个功能正好给 X」：

> 钩子：高敏 + 创伤 + 野心家，低谷期只会向内求，把自己当替罪羊
> 缺的：一把**尺子** —— 量不出这段难有几分是自己、几分是时运
> 功能：人生 K 线（`life-kline`）—— 把一生运势画成有涨有跌的线
> 落点：命理不是免罪符（甩锅给命），是一个**坐标**（知道自己正站在低处，这段本来就难，会过去）

这个「痛点 → 缺的东西 → 功能给了它 → 哲思落点」是**主力线的万能骨架**。

## 八、常用口吻：创始人手记

「我做的这个 AI…」「我最近把它的 X 模块做完了…」

好处：
- 天然是 AI 科技向（讲产品不讲算命）
- 有位置、有代价，人味儿足
- 不是营销，是分享
- 用户对「一个人在认真做东西」有天然好感

## 九、标签

10 个左右。原则：

- 一半泛流量（`#AI工具` `#自我探索` `#当代年轻人状态`）
- 一半精准（`#AuraMate` `#AI灵体` `#东方哲学`）
- **不带任何违禁词**
- 不带「抖音」等平台名

已验证的安全标签池：
```
#AI灵体  #AI工具  #东方哲学  #人格类型  #当代年轻人状态  #自我观察
#形态图鉴  #数字日记  #实况图  #自我探索  #情绪价值  #独立开发
#产品日常  #AuraMate  #灵伴
```

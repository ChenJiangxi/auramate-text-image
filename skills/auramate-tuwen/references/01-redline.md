## 三、高危选题方向（别碰）

- 玄学正面切入：直接讲算命 / 改运 / 风水布局 / 命盘看人
- 服务承诺式：「找我看 X」「私信送命书」「+V 算 X」
- 夸大式：「100% 准」「她照做改运了」「大师私藏秘法」
- **预测危险事件**：疾病 / 死亡 / 灾祸。这条最危险，会被判封建迷信+制造焦虑

## 四、图片红线（比文字更容易翻车）

| 规则 | 出处 |
|---|---|
| **图里不能带信息** —— AI 长输出截图、满屏文字报告、任何读起来像营销的句子，一律不行 | 2026-05-18 用户：「图文的话不要带信息，会被举报」 |
| **灵体必须真截图** —— 不准 CSS 渐变球 / emoji / mockup | 2026-06-01 用户：「永远不要用球体替代灵体。要有产品图呀」 |
| **竞品用真 logo** —— DeepSeek / Gemini / OpenAI 用官方矢量，不准文字圆标 | 2026-06-16 用户：「其他模型的照片不要敷衍，要真实的logo」 |
| **产品截图要完整 + 铺满** —— 不放截断的半张，不留大片留白 | 2026-07-01 |
| **不写「真实产品截图」这种自我标注** —— 显假、像广告。用第一人称叙述当 label | 2026-07-01 |

### 产品截图裁剪要点

命理功能页主体常是干支矩阵（满屏红词），但**别一看就整张弃掉** —— 里面往往有干净局部能用：

- 评分环（「82 财运」）
- 折线 / K 线趋势图 ← **最佳**，既干净又信息量大
- 雷达图 / pentagon
- 月份标签、热力图、地图

优先选**一张顶一屏**的信息密集图（12 个月的折线 > 一个小评分环）。用户 2026-07-01 原话：「信息量太少」。

## 五、发布前 checklist

跑完 `tools/redline-scan.sh`，再人工过一遍：

```
□ 标题 + 正文 + 标签，违禁词扫一遍（脚本 + 肉眼）
□ 每张图的文字，违禁词扫一遍（包括产品截图里露出的字）
□ 「抖音」全部换成 🫘
□ 没有「评论区扣 / 私信我 / 加 V」类引导
□ 没有「100% / 必准 / 包灵验」类夸大
□ 不预测疾病 / 死亡 / 灾祸
□ 玄学元素藏在 AI / 工程 / 古典文化壳子里，不正面 push
□ 灵体是真产品截图，不是渐变球
□ 产品截图完整、铺满、没有大片留白
□ 图里没有大段 AI 输出文字
□ 小标题不是「真实产品截图」这类自我标注
□ 底部只有品牌签或中性陈述，没有强 push
□ 主页简介 / 话题不出现高危词
```

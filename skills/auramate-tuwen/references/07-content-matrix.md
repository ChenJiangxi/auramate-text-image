## 一个 C 端 AI 玄学品牌，图文该有什么

按**目的**分四层，不是按题材分。每一层缺了，账号就有一块短板。

```
认知层（拉新）      让不认识的人刷到 → 叙事随笔 / 知识解析 / 节令热点
互动层（涨粉）      让刷到的人留下 → 图鉴自测 / 灵体大赏
信任层（转化）      让留下的人相信 → 功能上新 / 数据背书 / 幕后翻车记
陪伴层（留存）      让相信的人常来 → 日签日更 / 幕后日常
品牌层（护城河）    让人认可你这个人 → 创作理念（立场抄不走）
```

**为什么叙事随笔占一半**：它同时满足三个约束 —— 天然 AI 科技向（讲产品不讲算命）、天然人味儿（第一人称有代价）、天然不带信息（图里只有短句）。风险最低、复用最强、已跑通 6 篇以上。

**你提的三个的定位**：
- **功能更新** → 必须有，但**不能当主力**。纯上新帖在小红书是"广告"，一个月两篇顶天了。要叙事随笔和知识解析把它托住。
- **抽奖活动** → **改成办比赛**（用户 2026-08-10 拍板）。抽奖零内容沉淀、还是平台重点监控的营销行为；
  「灵体大赏」这种 UGC 征集能产出一批带话题的用户笔记、让用户替你展示产品最好看的部分，
  合规风险还低得多（带标签正常发笔记 ≠ 引导评论）。奖品走月度会员。详见 `tuwen-campaign-contest`。
- **十神解析** → **这个最有价值**，是我最看好的一条线。原因：十神是玄学里唯一能"科普化"的体系（十个类型，像 MBTI），收藏率高、有系列感、能反复做。但"十神""伤官""印"是违禁词 —— 必须翻译成产品自己的一套形态名（见下）。

### 我还想加的五条线（你没提的）

1. **心理钩子 reframe**（归入叙事随笔）—— 拿一个热门心理概念（高敏感 / 讨好型 / 内耗 / 课题分离 / NPD）当钩子，桥到功能。**这是目前最稳的爆款公式**，用户自己就在用这个方式给选题（发一张别人的抖音封面 + 「下一个选题按这个方向」）。
2. **数据背书** —— 你们有别人没有的东西：一篇论文、一个 benchmark、灵伴 37.5% 超过所有通用大模型。这是把"又一个算命 app"和"认真做的 AI 产品"分开的唯一武器。一个月一篇。
3. **幕后日常 / 翻车记** —— 「用户说这个功能不准，我去查了代码，发现是……」。人格化最快的路径，也最安全（纯工程叙事，零红线）。
4. **使用教程 / 报告怎么读** —— 收藏率天花板。已经付费的用户也会看。
5. **创作理念 / 立场帖** —— 已单独成 skill（`tuwen-manifesto`）。用户 2026-08-10 提的：
   「要显示你对八字的理解（不违规的情况下），大家认可你的产品理念才会被吸引」。
   立场是抄不走的护城河，而且零红线，限流后拿来洗白最合适。一个季度 1–2 篇。

## 发布节奏

- **稳定 > 爆发**。账号高危期，每周 3–4 篇，别突然一天发五篇。
- **危险的和安全的交替**。发过一篇擦边的，下一篇必须是纯工程 / 纯数据。
- **19:00–22:00** 是这个受众的活跃时段。
- 一篇发出去 **48 小时内别发同类型**的，会互相抢流量。
- 数据掉底 → 立刻查是否踩线 → 接下来两周只发最保守的内容洗白。

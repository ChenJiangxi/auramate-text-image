# 06 · 发布包 / 交付

## content.md 格式（每篇必写）

这个文件是给未来的自己看的 —— 半年后要复用这个选题、或者用户说「上次那种再来一个」，靠它。

```markdown
# post — {标题}（{功能中文名} / {feature-id}）

{第几篇 / 用的什么模板 / 用户是怎么提的（引原话 + msg 编号）/ 发出去没}

## 概念 / 角度映射
钩子来源：{用户给的图 / 热点 / 心理概念}
映射到功能：{功能名}（metamate `{id}`，config.ts:{行号}，{分类}）
逻辑桥：{为什么这个钩子接得到这个功能}

## 素材
- 插画：`assets/illustration.png`（codex 生成，prompt 要点：…；session 已关）
- 产品截图：
  - `{源路径}` → `assets/pf-chart.png`（裁剪坐标 {x,y,w,h}，选它是因为…）
  - 备用：{其他候选}

## 文案
封面：{标题，标注哪个词是 accent}
（slide-2 痛点）{全文}
（slide-3 reframe+功能）{全文}
（slide-N 落点）{全文}

## 分镜 · 视觉
{N} 张。1 封面（标题 {字号} + {配图}）/ 2 {…} / 3 {…} / 4 产品图 {文件名}（head「{说明}」foot「{标注}」）…
正文 44px，portrait 截图 height:100% 居中。

## 红线
命中风险词：{列出}。{哪些平台 OK，小红书需要怎么软化}
扫描：redline-scan.sh 已过 / 图内文字已肉眼核

## 发布信息
标题：{≤20 字}
正文：{300-600 字全文}
标签：{10 个}
```

## 扫描 content.md 会误报

`content.md` 的「红线」段通常会写「避开了 X / Y / Z」，扫描器照单命中。
**权威的一遍是只扫 slide** —— 那才是真要发出去的东西：

```bash
tools/redline-scan.sh slide-1.html slide-2.html ...   # 真发内容
node tools/check-fill.js .                            # 留白
```

## 交付给用户的方式

陈江西在 dashboard 网页端，**看不到本机路径**。「保存到 X 了」等于什么都没给。

- 图片 → `mcp__hermit__attach_image`（PNG/JPEG/GIF/WebP，自动缩放，渲染在对话里）
- 文件 → `mcp__hermit__attach_file`（md / pdf / csv / zip，显示成下载条）
- 两个都接绝对路径 + 可选 caption

**一次发全套**：所有 slide 图 + 分镜说明 + 红线提醒 + 标题正文标签。别挤牙膏。

## 每阶段过用户

顺序：**选题 → 文案 → 出图 → 发布包**。每一步停下来等确认。

用户是协作型、自己也懂技术，希望你有判断有想法 —— 但不要一口气做完再问「行吗」，那样返工代价太大。

## 发布本身

- **小红书**：用户自己发。你交发布包。
- **抖音**：账号不在 agent 手里，用户自己发。只交素材包。

如果拿到了浏览器自动化权限要代发，那是**外部动作**，必须先明确确认。

## 评论区

- **不回复涉敏问题**（引导私信也不行，就是不回）
- 可以回：产品用法、纯情绪共鸣、感谢
- 提前把常见问题的安全答法写进 `replies.md` 备着

## 数据回收

发出去 3–7 天后回收：阅读 / 赞 / 收藏 / 评论 / 转发，记进 `INDEX.md` 的表格。

**看什么**：
- 收藏 > 赞 → 内容是「有用型」，往知识解析 / 教程方向加码
- 评论 > 赞 → 互动型选题成了，往图鉴自测方向加码
- 阅读高但互动低 → 封面成了，正文没接住
- 阅读突然掉底 → **可能限流了**，查这篇有没有踩线，接下来两周发保守内容

## 归档

发完清中间产物（`-v1` `-base` `.safe.png` 平行目录）。终版留一份，能从文件名秒分清是哪一版。

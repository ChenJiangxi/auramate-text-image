# 图鉴自测 · 让评论区自己动起来

**目的是互动，不是信息。** 这类帖的成败只看一件事：**读者有没有想说「我是 X」的冲动**。

已跑通：post-004「10 种 AI 灵体形态对号入座」（小红书 + 抖音双发）。

## 成立的三个条件

1. **类型数 8–12**。少于 8 不够挑，多于 12 划不完。
2. **每种要有画面感的名字**，不要抽象标签。「发疯日」「捡漏日」赢「伤官型」「偏财型」一万倍。
3. **每种配一句能对号的具体状态**，不是定义。「怪念头、发癫一下」不是「创造力强、表达欲旺盛」。

## 分镜（12 张标准版）

| # | 内容 |
|---|---|
| 1 | 封面：类型总清单 + 大字钩「你今天是哪一种」+ 一个灵体视觉 |
| 2–11 | 每种一张：形态名 + 一句状态 + 灵体视觉 |
| 12 | 收尾：HOW（这是什么做的）/ WHY（为什么会变）+ 开放式互动 |

小红书图文上限 18 张，实际 12 张读完率最好。

**8 张压缩版**：封面 + 每张放 1–2 种 + 收尾。

## 视觉

- 模板 B 浅底卡片风（`templates/card-light/`），一张一个观点，对比强
- 尺寸 1080×1440 或 1242×1660 都行，**全篇统一**
- **每张的灵体必须是真截图**（`~/HermitAgents/auramate-shared/lingti-orbs/` 或 `shishen-mov/` 抽帧）
- 排版跨 slide 完全一致，只换名字和句子 —— 用一个 `_form-template.html` + 脚本批量生成

## ⚠️ 互动怎么做（这里最容易踩线）

**绝对不能写**：
```
❌ 评论区扣 1
❌ 评论区告诉我你是哪种，我帮你看
❌ 第一个留言的送你 X
❌ 私信我 / 主页点这个
```
这些全是小红书「引导评论 / 引导私信 / 引导跳转」redline。

> post-004 的正文里写了「评论区留你猜的那个名字…第一个留言的，送你今天的形态解读」—— **那是当时的写法，现在不要再用**。用户后来明确定了铁律：不要「评论区扣」类互动诱导话术。

**可以写**（开放式陈述，不是指令）：
```
✅ 你今天是哪一种
✅ 十种全在图里
✅ 我自己最常出现的是顿悟日
```

区别在于：**陈述一个开放问题** vs **要求一个具体动作**。前者一样能激活评论区，后者会被判引导。

## 标题写法

- 「10 种 AI 灵体形态对号入座（哪个是今天的你）」
- 「我把东方传统里的十种状态做成了 10 个 AI 形态」
- 「你今天是哪一种」

封面大字三行：`东方十种状态` / `10 种 AI 灵体形态` / `你今天 —— 是哪一种？`

## 常见翻车

| 症状 | 修法 |
|---|---|
| 评论区没人说话 | 类型名太抽象，换成有画面的口语 |
| 用户说「灵体不好看」 | 换 orb 素材，或让用户重新生成。别用 CSS 假球 |
| 用户说「下面小字很丑」 | 去掉小字，一张只留形态名 + 一句状态 |
| 被判营销 | 检查是不是写了「评论区扣」类话术 |

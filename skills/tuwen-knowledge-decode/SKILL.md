# 知识解析 · 把玄学当古典数据集讲

**这是我最看好的一条线。** 十神这类体系天然像 MBTI —— 有限个类型、可对号入座、有系列感、能反复做。收藏率是所有类型里最高的。

**但也是最容易踩线的一条。** 这套体系的原生词汇几乎全在违禁表里。

## ⛔ 先过这道门槛：什么才算「解析」

**读者读完，能不能复述出一个他之前不知道的知识点？** 不能 → 废稿，重写。

这类最常见的失败模式，是写成**伪装成知识贴的功能贴**：

```
❌ 废稿结构
   「古人有一套东西叫 X」
   → 「它大概是讲人和外界关系的」
   → 「我把它做成了产品，每天自动变」
   读者学到了什么？零。这是产品介绍，不是解析。
```

```
✅ 合格结构
   「X 的真实结构是 A」        ← 一个具体、可复述的知识点
   → 「所以 B 和 C 的区别在这」  ← 用一对具体例子讲透
   → 「产品把它做成了什么样」    ← 一句带过，不是重点
```

**自检三条**：
1. 全篇有没有**至少 2 个具体概念被讲透**（不是被提到）？
2. 有没有说清楚**区别** —— 「A 和 B 都是 X，但差在哪」？
3. 把最后那段讲产品的话删掉，这篇还站得住吗？站不住 = 它本来就是广告。

> **真实翻车（2026-08-10）**：我做十神解析 demo，写成了「一千年前的人把关系拆成十种姿势，
> 这套东西叫十神，我把它做成了灵体形态」。用户一句话戳穿：「你觉得这是十神吗？」
> 确实不是——全篇没讲透任何一个概念，只有五句模糊转述，收藏价值为零。

## 十神的真知识点：五对，每对一个「稳」版一个「野」版

这是让十神能被科普化的**那个结构**，也是最值得讲的一层：十种不是十个平行标签，是**五对**，
每一对是同一种关系的温和版和失控版。古人给每对里两个名字分别带「正」和「偏」。

| 这一对讲的是 | 正 · 稳 | 偏 · 野 |
|---|---|---|
| 跟人**并肩** | 合作日 | 分享日 |
| 把东西**往外给** | 美食日 | 发疯日 |
| **拿到** | 搞钱日 | 捡漏日 |
| 被**管着** | 卷王日 | 压力日 |
| 被**托着** | 学习日 | 顿悟日 |

**「正」「偏」这两个字本身不是违禁词，可以直接用**，而且这层结构恰好是最有信息量的部分。
一期讲一对（成对页型 `templates/editorial-gradient/pair.html`），十种能做五期，天然是系列。

## 核心手法：双壳

玄学概念不能裸奔，必须同时套两层壳：

```
外壳 1（科技）：我们把它变成了 AI 能读的东西 / 数据 / 模型 / 可视化
外壳 2（文化）：这是古人的一套 X 系统（前心理学时代的人格模型 / 一千年前的季节健康模型）
```

- ❌「今天教你看十神」
- ❌「古人有十个词形容状态，我把它做成了 AI 灵体形态」← 这是**废稿**：只说了有这么个东西，没讲透任何一个
- ✅「同样是往外给，古人分成两种：一种是慢慢做喜欢的事，一种是憋不住炸开。他们连这个都要分开命名」

## 分镜（8 张标准版）

| # | 页型 | 内容 |
|---|---|---|
| 1 | 封面 | 反常识 + 具体。例：「古人形容状态分成五对，每对都有个失控版」 |
| 2 | 正文 | 为什么讲这个 —— 从一个现代痛点切入（不是"今天科普"） |
| 3 | 正文 | **把结构讲清楚**。这是全篇价值所在，别省 |
| 4–6 | 成对页/卡片 | 拆解。**一张讲一对**，用具体例子讲透区别。别一张塞十条 |
| 7 | 产品图 | 我们把它做成了什么 —— 真实产品截图。**一句带过，不是重点** |
| 8 | 正文 | 落点 + 系列钩（「下一期讲 X」建立追更） |

**成对讲的时候用 `pair.html`**：左右各一个形态、各用自己的真实帧、各一句话形成对照。
一对一张，比一次列十个好读得多，也更好做成系列。

**6 张压缩版**：封面 / 切入 / 来源 / 拆解 ×2 / 产品+落点。

模板 → `templates/editorial-gradient/`（叙述型）或 `templates/card-light/`（结构型，一张一个观点）

## 做成系列（这类的最大价值）

知识解析最适合系列化。系列的好处：追更、主页置顶、复用骨架。

已经能开的系列：

- **「古人的十种状态」** —— **一期讲一对，五期讲完**（并肩 / 往外给 / 拿到 / 管着 / 托着）。
  每期用成对页把「稳版 vs 野版」讲透，素材现成（`shishen-mov/` 一形态一段录屏）。
  比「十期各讲一种」好：对比本身就是知识点，单讲一种讲不出信息量。
- **「一千年前的数据集」** —— 五运六气 / 五行 / 大运，讲古典模型怎么被 AI 读
- **「时间坐标系」** —— 为什么出生时间要精确到小时 / 不知道时辰怎么办（接 `time-pillar`）

系列的 kicker 固定成 `灵伴 AI · {系列名} · {期号}`，视觉一致，用户一眼认出来。

## 红线特别提醒

1. **封面和标题绝对不出现原生术语**。「十神」「伤官」「印」在封面 = OCR 直接判。
2. **图里不要贴术语表**。一张满是「比肩 劫财 食神 伤官」的对照图 = 双重踩线（违禁词 + 图里带信息）。要讲对照，用形态名讲。
3. **不做「教学」姿态**。「教你看」「学会这个你就能」= 服务承诺式，触发 redline。用「我发现」「古人当时是这么想的」。
4. 讲历史可以放松，讲**应用**必须收紧。「宋代人怎么记录时间」安全；「怎么用它看自己」危险。
